- `skills_dictionary.json` : dictionnaire de compétences (~200 termes + synonymes). Créé et enrichi en **partie 3**. Format suggéré : `{"python": {"label": "Python", "synonyms": ["python3", "py"], "category": "programming"}}`.
- `naf_mapping.json` : correspondance **secteur affiché → codes NAF**, relue à la main (**partie 2**).
- `eval/` : jeux d'évaluation **synthétiques** (CV de test, entreprises annotées). Voir `docs/07-evaluation.md`.

**Interdit ici** : vrais CV, vraies données personnelles, dumps de base.
